# Object-Oriented Programming in Java

This repository contains Java programming coursework focused on object-oriented programming concepts and class construction.

Topics explored include:

- Class design
- Constructors
- Object instantiation
- Methods and attributes
- Encapsulation
- User input handling
- Basic object interaction and simulation

Example programs include vehicle modeling and interactive object-based programs written in Java.

Developed as coursework while studying discrete structures and computational mathematics.
